SUNCARE Hospital – Pharmacy Dashboard

📌 Project Overview

The SUNCARE Hospital Pharmacy Dashboard is an interactive Excel dashboard developed to analyze and monitor pharmacy operations. It provides clear insights into medicine sales, purchases, GST, revenue, expenses, stock and profit through KPI cards, charts and slicers.

🎯 Objectives

- Monitor pharmacy sales and purchase performance.
- Analyze medicine stock and transactions.
- Track GST-related sales and purchases.
- Identify pharmacy revenue and profit.
- Support better pharmacy management decisions.

📊 Key Features

- Total Sales
- Total Purchases
- Total GST
- Total Profit
- Medicine-wise Sales Analysis
- Purchase Analysis
- Stock Analysis
- Monthly Sales Trends
- Interactive Charts
- Slicers for filtering data

🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Power Pivot
- Excel Data Model
